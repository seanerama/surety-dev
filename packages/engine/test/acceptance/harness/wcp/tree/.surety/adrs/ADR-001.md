# ADR-001: Dependency-free static server and client-only plan in local storage

## Context

The specification requires a dependency-free Node.js static file server, a plain HTML/CSS/JavaScript client with no build step and no external CDN, and a plan stored only in this browser's local storage, with no server-side storage and no network calls beyond serving the static files.

## Decision

- `server.mjs` uses only Node.js built-ins and serves `public/` read-only; it has no API.
- The client is native ES modules (`public/js/*.mjs`) loaded with `<script type="module">`; no bundler, framework, package.json dependency or CDN.
- All state lives in the browser: one JSON value under `localStorage["cutPlanner.plan"]` in the shape of spec §9, read and written only by `public/js/store.mjs`.
- Tests use `node:test` and Node built-ins only.

## Consequences

- Nothing to install; `node server.mjs` is the whole runtime.
- Plans are per-browser and lost when browser data is cleared (an accepted limitation of the brief).
- Planner logic must be pure and DOM-free so that it can be unit-tested under Node without a browser library.
