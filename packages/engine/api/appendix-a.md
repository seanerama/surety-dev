- `adoption_baseline` (not dispatched in M1): eligible → claimed → executing → integrating → integrated → complete
- `conformance` (not dispatched in M1): eligible → claimed → executing → integrating → integrated → verifying → complete

Common transitions, applied to a kind only from the statuses it can reach:

- `return`: claimed, executing, integrating, verifying → eligible
- `park`: claimed, executing, integrating, verifying → parked
- `block`: executing, integrating, verifying → awaiting_decision
- `continue`: awaiting_decision → the stored continuation
- `stop`: claimed, executing, integrating, integrated, verifying, awaiting_decision → held (kinds whose path has claimed)
- `abandon`: claimed, executing, integrating, integrated, verifying, awaiting_decision → eligible (kinds whose path has claimed)
- `resume`: held → eligible
- `unpark`: parked → eligible
- `cancel`: eligible, claimed, executing, integrating, integrated, verifying, awaiting_decision, held, parked → cancelled

Statuses that own a run: claimed, executing, integrating, integrated, verifying, awaiting_decision. Continuations: executing, integrating, verifying. Terminal: complete, cancelled.
