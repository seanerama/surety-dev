# UI1 — engine acceptance rows for the operator console's prerequisites

**Owner:** Sean Mahoney. **Added:** 2026-10-23, for the console's engine prerequisite P1 (surety-console `docs/spec/UI1-build-spec.md` §4.1). One row, slice 47; rows M548 to M561 (slice 48) added 2026-10-27 under Sean's instruction that the assistant acceptance rows and the outstanding B2/assistant SEAM documentation accompany the implementation (recorded by the driver; the Verifier writes the files). The console's own rows (U01–U51) live in its repository and run under its harness; this plan holds only what the engine must do for the console to be hosted.
