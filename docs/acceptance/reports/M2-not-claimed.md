# What M2 does not claim

**Written by:** the Verifier, 2026-10-03, on branch `verify/m2-s10-close`, as the closing pass of M2 slice 10. **Status:** a running list toward the M2 acceptance report (M2 build spec §10: the report lists what M2 does not claim "in the form of `M1-not-claimed.md`"); it decides nothing, and it grows by a section per slice until the report is written. It is a separate file because `docs/acceptance/reports/M1-not-claimed.md` is the list behind M1's accepted claim, with M1's classes and counts, and slice 10 claims nothing about M1: its rows are M2's.

The classes are D2 §8's, as the M2 plan §4.4 carries them: **class A**, outside the threat model or unreachable by design; **class B**, real behaviour no test or canary has yet established; **class C**, an accepted limitation. Each entry names its row, the slice where it is claimed if one is planned, and the erratum that records it.
